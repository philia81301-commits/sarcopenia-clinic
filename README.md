# 肌少症篩檢紀錄工具

門診與社區篩檢站都適用的肌少症篩檢工具。單頁 HTML、無外部相依、可離線使用。

**線上使用：** https://philia81301-commits.github.io/sarcopenia-clinic/
**衛教頁（可直接給受檢者）：** https://philia81301-commits.github.io/sarcopenia-clinic/education.html

## 這個工具做什麼

兩段式流程：

1. **初篩** —— SARC-F 問卷加小腿圍（SARC-CalF）。SARC-F ≥ 4 或 SARC-CalF ≥ 11 為陽性。
2. **判定** —— 續做 **AWGS 2019**：握力、五次起坐、小腿圍，分出「肌少症可能」、
   「疑似肌少症」與「疑似嚴重肌少症」。

**初篩陰性者一樣可以加測**（標示為選填）。SARC-F 對早期肌少症的敏感度有限，初篩陰性
不等於沒有肌少症；加測後才發現肌力或體能低下的個案，結果會標註「初篩未達切點，以實測為準」。

**五次起坐為選填**，現場沒時間可留空。留空時結果標為「部分評估」——嚴重肌少症需肌力與
體能同時低下才能認定，少測一項就無法排除，畫面會明講。

判定為陽性時，畫面會出現一個 QR code，受檢者用手機掃描即可看到運動與蛋白質衛教內容。
該頁面不含任何個人資料。

## 現場使用注意

- **每台裝置開工前先選一個不同的工作站代碼（A–H）**，否則多台裝置會產生相同的受檢者代號。
- **姓名記在紙本對照表**，不要輸入工具。系統只送出代號、場域、出生年、性別與測量值。
- 小腿圍請照畫面上的量測提示做，不同人量出來的數字才能互相比較。
- 握力／五次起坐**填了就要按「產生判定結果」**，否則不會被記錄（系統會擋下並提醒）。
- 工具最上方有「使用說明（含離線操作）」，第一次開啟時自動展開。

## 離線使用

工具是 PWA，**第一次連著網路開啟後就會存進裝置**，之後斷網也能照常篩檢。

- 建議用瀏覽器的「**加到主畫面**」，之後像 App 一樣點圖示開啟。
- 離線時最上方會出現「目前離線」提示列；紀錄存在本機，回到有網路後到「今日統計」按
  「**一鍵補送**」。
- 要離線很久或換裝置前，先按「**匯出 CSV 備份**」。清瀏覽器資料會把未送出的紀錄一起清掉。
- 頁尾顯示目前版本與離線狀態，可用來確認各台裝置跑的是不是同一版。
- 出現「已有新版本」時，**先送出手上這位**再按「立即更新」（更新會重新載入頁面）。

**三個限制**：從沒連網開過的裝置離線打不開；病人掃衛教 QR 需要他自己手機的網路；
以 `file://` 直接開啟時 Service Worker 不會運作（要透過網址開）。

## 限制

小腿圍只是肌肉量的**代理指標**，本工具不能用於確診。確定診斷需在醫療院所以 DXA 或 BIA
測量肌肉量。所有結果文字皆標示為「疑似」，並提示轉介。

工具內不寫死健保給付條文，請以就診當時的公告為準。

## 開發

| 檔案 | 用途 |
|---|---|
| `index.html` | 主工具 |
| `education.html` | 靜態衛教頁 |
| `sw.js` | Service Worker（離線快取；網頁走 network-first） |
| `manifest.webmanifest` | PWA 設定（加到主畫面的名稱、圖示、顏色） |
| `icon-192.png` / `icon-512.png` / `icon-512-maskable.png` | PWA 圖示 |
| `docs/google-form-fields.md` | Google 表單欄位對照表 |
| `tools/make-qr.py` | 重新產生並嵌入衛教頁 QR（只有網址變更時需要） |
| `tools/make-icons.py` | 重新產生 PWA 圖示（可重複執行，結果固定） |
| `agents.md` / `handoff.md` | 專案藍圖與進度交接 |
| `rdq/` | 需求規格卡 |

改版時 `sw.js` 的 `VERSION` 與 `index.html` 的 `APP_VERSION` **要一起改**，否則圖示、
manifest 這類 cache-first 的檔案不會在既有裝置上更新。

本機預覽：

```
python -m http.server 8765 --directory .
```
