# Google 表單欄位對照表

`index.html` 只送這 11 個欄位。**姓名、電話、身分證、出生月日一律不送。**

建好表單後，把每題的 `entry.xxxxxxxxx` 填進 `index.html` 最上方的 `ENTRY` 物件，
並把表單網址中的 formId 填進 `FORM_ID`。兩者都填好之後，頁面上方的「上線前待辦」提示會自動消失。

| 程式欄位 | Google 表單題目建議寫法 | 題型 | 值 |
|---|---|---|---|
| `site` | 受檢場域 | 簡答 | `clinic`＝門診、`community`＝社區 |
| `code` | 受檢者代號 | 簡答 | `YYYYMMDD-<工作站><流水號>`，例 `20260801-B007` |
| `birthYear` | 出生年（西元） | 簡答 | 例 `1948` |
| `gender` | 生理性別 | 簡答 | **`0`＝女、`1`＝男**（沿用門診既有編碼） |
| `falls` | 過去一年跌倒次數 | 簡答 | 整數 |
| `calf` | 小腿圍（公分） | 簡答 | 一位小數 |
| `sarcf` | SARC-F 分數 | 簡答 | 0–10 |
| `stage1` | 初篩結果 | 簡答 | `positive` / `negative` |
| `grip` | 握力（公斤） | 簡答 | 初篩陰性者為空值 |
| `sts` | 五次起坐（秒） | 簡答 | 初篩陰性者為空值 |
| `result` | 判定結果 | 簡答 | 見下表 |

## `result` 的五種值

| 值 | 意義 |
|---|---|
| `screen_negative` | 初篩陰性 |
| `no_finding` | 初篩陽性，但握力與五次起坐都未達切點 |
| `possible` | 肌少症可能（低肌力或低體能） |
| `sarcopenia` | 疑似肌少症 |
| `severe` | 疑似嚴重肌少症 |

## 建立表單時的注意事項

- **全部用「簡答」題型**，不要用下拉或單選。程式是背景 POST，選項題只要值對不上就會被 Google 靜默拒收。
- **不要設必填**。初篩陰性者的 `grip`、`sts` 是空值，設必填會整筆送不進去。
- 建好後務必**實際送一筆測試資料**，確認回應表每一欄都對得上位置再上線。
- 取得 entry 編號：開啟表單預覽 → 檢視原始碼 → 搜尋 `entry.`；或用「取得預先填入的連結」複製網址後看參數。

## 多台裝置同時作業

回應試算表就是**統整後的唯一名單**，各裝置送出的紀錄會自動合併，不需要有人去收 CSV 檔。

每台裝置開工前要在畫面上選一個不同的**工作站代碼**（A–H），代號才不會撞號。
現場紙本對照表建議也照工作站分開一台一張，收工時一起交回。

`匯出 CSV 備份` 只在斷網或表單異常時用，檔案會落在該台裝置自己的下載資料夾
（Windows 是 `Downloads`、iPad 是「檔案」App 的下載項目），檔名含工作站代碼。

## 分析時的提醒

- 分組統計前先確認 `site` 與 `gender` 的 distinct 值，避免混入手動補填的異常寫法。
- 任一組 **n < 10 時不要把百分比當成亮點**，列分子分母即可。
